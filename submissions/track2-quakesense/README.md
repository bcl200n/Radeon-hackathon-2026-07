# QuakeSense — code-only snapshot

This pull request currently contains source code only.

Presentation decks, demo media, generated WebGIS pages, run outputs, evidence
files, and local knowledge/data assets are intentionally withheld from public
review. They are retained in the project's private local and OneDrive backups.

## Included

- Agent and simulator implementation
- Data-building and benchmark scripts
- WebGIS generator source
- Regression tests
- Environment and reproduction instructions

See [`source/README.md`](source/README.md) for the code layout and local setup.

## Local-data policy

Large inputs, city-specific data, generated caches, run summaries, logs,
figures, presentations, and videos must remain outside the repository. The
provided scripts expect those assets to be supplied from a private local data
directory.

QuakeSense is a research and decision-support prototype, not an official
emergency-management system.
